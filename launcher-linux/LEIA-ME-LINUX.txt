BLACK PC - MOD LOADER 1.4.27 - LINUX
====================================

Launcher nativo para Linux do ModLoader do BLACK PC port (Spark198rus).
E o mesmo launcher do Windows (mesmas abas, mesmos ajustes, mesmo visual),
compilado para Linux; o JOGO e o blackrt.dll (modloader) sao Win32 e rodam
pelo Wine. O modloader NAO e uma DLL Linux: ele e carregado pelo black.exe
dentro do prefixo Wine.

COMPATIBILIDADE
---------------
- So com o BLACK PC port do Spark198rus (nao com o BLACK-XBERecomp do TGP482).
- Compativel com o BLACK PC port 0.3.0 (e com o 0.2.1): as opcoes novas do port
  0.3.0 aparecem no launcher e as opcoes antigas continuam exatamente iguais.
- Precisa do jogo com dump na pasta game/ (default.xbe + arquivos). Este pacote
  NAO inclui o jogo.

REQUISITOS
----------
- Linux x86-64
- Wine (de preferencia com suporte 32 bits, porque o port e Win32)
- Nada de .NET instalado: o launcher ja vem completo nesta pasta.

Debian/Ubuntu:
    sudo apt install wine wine32
    (em sistemas 64 bits com suporte a i386: sudo dpkg --add-architecture i386
     e depois sudo apt update && sudo apt install wine32:i386)

Fedora:
    sudo dnf install wine

Opcional (som do launcher): mpv ou ffplay (ffmpeg) no PATH.

INSTALACAO
----------
1. Tenha o port do Spark198rus com o jogo (dump NTSC-U) na pasta game/.
2. Feche o jogo.
3. Extraia este ZIP na pasta do port (a mesma do black.exe).
4. Execute:
       bash run-blacklauncher.sh
   (ou dê permissao de execucao duas vezes e abra run-blacklauncher.sh pelo
   gerenciador de arquivos: chmod +x run-blacklauncher.sh launcher-linux/blacklauncher)

O launcher encontra o port pela pasta onde ele esta ("--port" ja vai no script).

O QUE ELE FAZ
-------------
- add-on de terceiros BLACK Reloaded Mod (kROM3r,
  https://github.com/kROM3r/BLACKReloadedMod): copie a winmm.dll do pacote
  dele para a pasta do black.exe (sem trocar o blackrt.dll); os mods de
  jogo rodam junto, mas as telas dele sao do menu do port 0.2.0;
- mods de armas, animacoes e texturas feitos com o Black 2006 Modding tools
  (pedrolZasx, https://github.com/pedrolZasx/Black_2006_Modding_tools): a pasta
  do mod com os .db no caminho do jogo (levels/<fase>/fpguns/<arma>.db); para
  armas grandes use AUDIO E JOGO > Buffers de arma = 8 MB;
- le e grava o black.ini (todos os ajustes das abas VIDEO, GRAFICOS,
  DESEMPENHO, AUDIO E JOGO, CONTROLES, MODS e AVANCADO);
- lista os mods de mods/ e liga/desliga (o estado fica no proprio mod);
- abre o jogo com Wine e mostra o relatorio de erro se ele fechar com erro;
- procura atualizacoes no GitHub e instala o pacote ...-linux.zip.

O launcher NUNCA copia por cima de black.ini, savedata/, game/ nem dos seus mods.
O blackrt.dll deste pacote ja e o modloader: a extracao do ZIP sobre a pasta do
port substitui o blackrt.dll do port (guarde uma copia se quiser voltar atras).

WINE
----
O launcher usa o comando "wine" por padrao. Para escolher outro comando, outro
prefixo ou desligar o DXVK, crie/edite launcher.ini AO LADO do blacklauncher
(launcher-linux/launcher.ini):

    wine = wine
    wineprefix = /home/jogador/.wine-black
    dxvk = 1

  wine         comando do Wine (wine, wine64, /caminho/para/wine)
  wineprefix   WINEPREFIX usado para abrir o jogo (vazio = o padrao do sistema)
  dxvk         1 = d3d9 via DXVK (WINEDLLOVERRIDES=d3d9=n,b), 0 = wined3d

DXVK costuma ser bem mais rapido que o wined3d. Se o driver Vulkan nao funcionar,
coloque dxvk = 0.

Um prefixo 32 bits (WINEARCH=win32) e o mais indicado para o port Win32:
    WINEARCH=win32 WINEPREFIX=~/.wine-black wineboot -u

O jogo continua sendo black.exe Win32; o Wine roda ele no Linux.

ATUALIZACOES
------------
A aba AVANCADO > PROCURAR ATUALIZACAO consulta
    https://api.github.com/repos/DarketzOficial/black-pc-modloader/releases/latest
e baixa o asset ...-linux.zip. A troca dos arquivos acontece no proximo inicio
do launcher (o pacote e extraido agora e aplicado antes da janela abrir).
Nao toca no jogo nem nos saves.
